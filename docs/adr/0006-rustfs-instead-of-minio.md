# ADR 0006. RustFS вместо MinIO

- Статус: принято
- Дата: 2026-10-23

## Контекст

`SPEC.md` предусматривал MinIO как S3-совместимое хранилище фото и файлов. В сентябре 2026 года MinIO удалил образы `minio/minio` и `minio/mc` из Docker Hub, а копия на quay.io перестала отдаваться без учётной записи. Первый же `docker compose pull` у заказчика упал с `pull access denied for minio/minio`.

## Решение

- В `docker-compose.yml` сервис `minio` заменён на `rustfs` (образ `rustfs/rustfs:1.0.0`, лицензия Apache 2.0). Порты прежние: 9000 — S3 API, 9001 — веб-консоль.
- Переменные окружения переименованы в нейтральные: `S3_ACCESS_KEY`, `S3_SECRET_KEY`; `media-service` получает адрес `http://rustfs:9000`.
- Сервисы работают с хранилищем только через S3 API (AWS SDK v2), поэтому смена хранилища не затрагивает код.
- Бакеты создаёт сам `media-service` при старте (этап 4), отдельный контейнер с клиентом не нужен.

## Последствия

- Если RustFS не подойдёт под нагрузкой (проверка на этапе 4), его можно заменить на Garage или SeaweedFS правкой одного сервиса в `docker-compose.yml`.
- В `SPEC.md` упоминания MinIO заменены на «S3-хранилище».
