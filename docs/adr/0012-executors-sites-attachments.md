# ADR 0012. Исполнители, площадки, документы акта, удаление актов, оформление Excel

- Статус: принято (уточнения заказчика после этапа 5, раздел 19 SPEC.md)
- Дата: 2026-10-24

## Решения

1. **Исполнители** — новая таблица `executor_company` в `directory-service`, а не флаг у организаций-заказчиков: у исполнителя свои правила (ровно один основной, изменяет только администратор). Основной исполнитель создан миграцией; в акт исполнитель копируется снимком (`work_act.executor_*`). Для старых актов без снимка печать берёт реквизиты из настроек `document-service`.
2. **Площадки** — таблица `site` в `directory-service`, связь «техника → площадка». Блокировка вместо удаления (`is_active`). Уже назначенную заблокированную площадку можно оставить у техники и в акте, выбрать заново — нельзя. Подразделения остаются отдельным понятием.
3. **Номер акта с кодом площадки.** Счётчик `act_number_sequence` ведётся по ключу `(год, префикс[-код])`, поэтому у каждого кода свой ряд номеров, а номера разных кодов не пересекаются по построению. Уникальность при одновременных запросах обеспечивает атомарная команда PostgreSQL (см. ADR 0008).
4. **Удаление незакрытых актов** — физическое, каскадом. Пропуск номера допустим: удалённый номер не выдаётся повторно. Событие `ActDeleted` пишется в outbox. Ежедневная задача (`@Scheduled`) удаляет аннулированные акты старше 30 дней. При нескольких экземплярах `act-service` задача может выполниться на каждом — это безопасно (удаление идемпотентно); блокировка ShedLock — в бэклоге.
5. **Документы акта** хранит `media-service` (назначение `ACT_ATTACHMENT`, превью только у изображений); `act-service` хранит привязку (`act_attachment`) и берёт имя, тип и размер файла из `media-service`, проверяя, что файл загружен именно для этого акта. Отметка «скан подписан» — итоговое поле `work_act.has_signed_scan`.
6. **Excel:** палитра и рамки собраны в `ExcelStyles`; формат чисел «Общий»; высота строк — по самому длинному тексту в строке с запасом (`SheetWriter.heightForAll`), т. к. Excel не подбирает высоту объединённых ячеек.
