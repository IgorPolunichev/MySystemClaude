# ADR 0017. Рабочие графики (раздел 19.15 SPEC)

- Статус: принято, реализуется по частям (19.15а — ядро и API)
- Дата: 2026-10-25

## Решения

1. **Модуль внутри `analytics-service`, а не отдельный сервис.** Графикам нужны производственный календарь, нормы и факт часов по актам — всё это уже в `analytics-service`. Отдельный сервис означал бы межсервисные вызовы на каждый расчёт дашборда, новую базу и контейнер без пользы. Модуль изолирован пакетами `domain.schedule`, `ScheduleService`, `ScheduleStore`, `ScheduleController` и маршрутом `/api/v1/schedules/**`; его можно вынести позже.
2. **График не хранится по дням.** Хранятся шаблон конструктора, группа (дата начала, требуемое покрытие), состав бригад (бригада, порядок смен, смещение заезда, сменщик) и ручные отметки. Смена сотрудника на любую дату вычисляется (`ScheduleGenerator`) — поэтому график строится на год вперёд мгновенно, а правки не требуют пересчёта.
3. **Правила построения.** Сменный/вахтовый N/M: цикл N + M, бригада А заезжает в дату начала, Б — через N − k (k — пересекающиеся дни). При ночных сменах подгруппы «сначала день» и «сначала ночь» меняются местами через s дней (s = 0 — не меняются); при нечётном числе лишний человек остаётся всю вахту в приоритетной смене. Отсыпной при переходе с ночных на дневные — по галочке. 5/2 — рабочие дни производственного календаря. Смещение заезда сдвигает и сменщиков. Ручные отметки: отпуск, больничный, рабочий день вместо выходного (разовое продление вахты).
4. **Норма суток:** дневная смена целиком; ночная делится по полуночи пропорционально (с учётом перерыва): 20:00–08:00 с часом перерыва = 3 ч 40 мин к дню начала + 7 ч 20 мин к следующему.
5. **Покрытие и нехватка** считаются по каждому дню против требуемого числа людей днём и ночью (по умолчанию — как в полной бригаде, можно изменить). Предупреждения: разрыв между бригадами (дней на смене меньше, чем дней отдыха + пересекающиеся дни), нечётное число сотрудников.
6. **Особенность смены мест «день ↔ ночь»:** в день перехода работавшие ночью не могут сразу выйти в дневную смену, поэтому дневная смена бригады в этот день пуста — график показывает это как нехватку, руководитель закрывает вручную или выбирает режим без смены мест.
7. **Права:** составляют, правят и утверждают администратор и руководитель (своего отдела); смотрят все. Любая правка снимает утверждение.
