# Допущения

Принятые решения по разделу 18 «Допущения, которые нужно подтвердить» из `SPEC.md`. Заказчик подтвердил, что для всех вопросов действуют варианты «По умолчанию».

## Основные вопросы

| № | Вопрос | Принятое решение |
| --- | --- | --- |
| 1 | Архитектура | Микросервисы, как в разделе 4 |
| 2 | Кто редактирует открытый акт | Автор и все участники акта |
| 3 | Отделы и роль руководителя | Отделы сервисной компании, роль `DEPARTMENT_HEAD` есть |
| 4 | Запчасти «со склада» до появления склада | Запчасти вводятся вручную, при наличии в каталоге — из каталога |
| 5 | Цены и суммы в акте | Нет, только количества |
| 6 | Интеграция с 1С и др. | Только письмо, интеграция позже отдельным сервисом |
| 7 | Отправка писем | Оба режима: SMTP и `.eml` |
| 8 | Утверждённая форма акта | Нет, форма по разделу 7 |
| 9 | Фото на листе техотчёта | 6 (сетка 2 × 3) |
| 10 | Работа без интернета | Да, нужна |
| 11 | Время в пути и ожидание | Отдельное необязательное поле вне продуктивных часов; галочка «Скрыть время в пути» стоит по умолчанию |
| 12 | Размещение | Docker Compose на собственном сервере в РФ |
| 13 | Active Directory | Нет, учётные записи в Keycloak; AD подключается позже |
| 14 | Номер акта | `АВР-ГГГГ-NNNNNN`, сброс ежегодно, единая нумерация |
| 15 | Подписанты | Один представитель заказчика, все инженеры акта |
| 16 | Электронная подпись | Нет, подписи ставятся на распечатке |
| 17 | Нагрузка | До 200 пользователей, до 5 000 актов в месяц |

## Вопросы по новым функциям

- «Скрыть реквизиты» — скрываются реквизиты обеих сторон (исполнителя и заказчика), наименования остаются.
- Профили формы настраивает только администратор.
- Офлайн-клиент — PWA для всех устройств.
- Работа без связи — до 7 дней подряд.
